#### what i'm building

- **Rakhsha** — personal-safety android app that watches for falls, struggles, snatches and crashes. *built solo; field-tested with volunteers on real devices.*
- **[Web Scraper Pro](https://github.com/D1bakar/web-scraper)** — self-hosted scraping platform: 11 extraction modes, price compare, REST API.
- **[argos](https://github.com/D1bakar/argos)** — active web vulnerability scanner for **authorized** security testing.
- **pulse** — observability & health bot for a **20,000-member** discord dev community.
- **[bridge-drop](https://github.com/D1bakar/bridge-drop)** — lan-only phone ↔ pc transfer; resumable chunks, nothing leaves your network.
- **[autofile](https://github.com/D1bakar/autofile)** — sorts loose files by type; dry-run by default, project folders never touched.
- [more on github →](https://github.com/D1bakar?tab=repositories)
